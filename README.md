# Simulado DETRAN-MG

Site PHP para treinar e fazer simulados da prova teórica (30 questões, 20 acertos).

## Hostinger

1. Deploy do repositório na raiz do domínio.
2. phpMyAdmin: importar `database.sql` e depois `seed_100_questoes_mg.sql`.
3. Conexão MySQL: `config/database.php` (copiar de `database.example.php` e ajustar senha se precisar).

## Uso

- **Treinar** — questão a questão com gabarito.
- **Simulado** — prova completa.
- **Progresso** — histórico no navegador.
